# Super-Drawing-Master
MATLAB 机器人数据可视化分析工具：一个用于分析和可视化机器人运动数据的MATLAB脚本，能够从CSV数据文件生成多种专业图表。
功能概述
该工具提供全面的机器人性能分析，包括：
高度与速度分析​ - 目标值与实际值对比
关节运动分析​ - 左右关节的速度和扭矩
轮毂性能分析​ - 轮毂速度、扭矩和功率计算
姿态角分析​ - 横滚角、俯仰角和偏航角
腿长监测​ - 左右腿实际长度跟踪
快速开始
数据文件要求
CSV格式数据文件
包含时间戳、高度、速度、关节数据、轮毂数据、姿态角等列
文件应放置在脚本同目录下
基本使用
修改配置区域的文件名：
复制
data_raw_name = 'your_data_file_name'; % 修改为实际文件名（不含.csv后缀）
运行脚本，自动生成综合可视化图表
图表配置系统
脚本采用灵活的配置结构，支持：
主图布局
4×3网格布局显示11个关键指标图表
统一配色方案和字体设置
自动极值标注功能
单独图表输出
特定重要图表（如关节扭矩）可单独显示和保存：
复制
plot_configs(4).save_separate = true; % 关节扭矩图单独显示
核心功能模块
数据加载与处理
自动路径定位和时间戳转换
多数据类型提取（关节、轮毂、姿态等）
功率计算：P = ω × τ
可视化特性
目标值 vs 实际值对比显示
极值自动标注（最大值/最小值）
专业配色方案：
深蓝色：左关节/轮毂
浅蓝色：右关节/轮毂
橙色：目标值
紫色：实际值
图表类型
高度对比​ - 机器人高度跟踪性能
速度对比​ - 运动速度响应
关节速度​ - 左右关节角速度
关节扭矩​ - 关节输出力矩（可单独显示）
轮毂速度​ - 轮子旋转速度
轮毂扭矩​ - 轮子输出扭矩
横滚角​ - 机器人横滚姿态
俯仰角​ - 机器人俯仰姿态
偏航角​ - 机器人偏航姿态
实际腿长​ - 左右腿长度变化
轮毂功率​ - 左右轮功率消耗
自定义配置
修改图表显示
在plot_configs结构中调整子图位置和保存设置：
复制
plot_configs(1).subplot_pos = [4,3,1]; % 主图位置
plot_configs(1).save_separate = false; % 是否单独保存
颜色方案定制
修改全局颜色顺序：
复制
global_color_order = [0 0.4470 0.7410;   % 深蓝色
                      0.3010 0.7450 0.9330; % 浅蓝色
                      0.8500 0.3250 0.0980; % 橙色
                      0.4940 0.1840 0.5560]; % 紫色
输出选项
主图保存
取消注释最后几行代码即可保存综合图表：
复制
% combined_filename = [data_name, '_combined.png'];
% saveas(main_figure, combined_filename);
单独图表
配置save_separate = true的图表会自动创建单独窗口，便于详细分析和导出。
兼容性说明
支持MATLAB R2018b及以上版本
自动处理Yaw角数据兼容性
灵活的数据列名适配
技术特点
模块化设计​ - draw_plot函数统一处理所有图表绘制
自动化标注​ - 极值点自动识别和标注
专业可视化​ - 学术论文级别的图表质量
易于扩展​ - 可轻松添加新的分析图表
